# Chatbot Engine

## Objetivo
Construir un motor de chatbot reutilizable para múltiples empresas.

## Cliente actual
Servicell

## Tecnologías
- Node.js
- Express
- Claude API
- Supabase
- Railway
- WhatsApp Cloud API
- Instagram Messaging API

## Principios
- Arquitectura modular.
- Reutilizable para múltiples clientes.
- Separar lógica del motor y configuración del cliente.
- No duplicar código.
- Código limpio y documentado.
